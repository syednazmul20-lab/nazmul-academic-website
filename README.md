# Syed Nazmul Hasan — Academic Portfolio Website

This is a complete responsive static website. It works without a build step.

## Preview
Open `index.html` in any modern browser. Internet is only needed to load the optional Google Fonts and to visit external Scholar links.

## Publish
Upload all three files (`index.html`, `styles.css`, `script.js`) to the root of any static web host, such as Netlify, GitHub Pages, or Cloudflare Pages. The three files must stay in the same directory.

## Updating your site
- Edit the intro, affiliation, and contact section in `index.html`.
- Edit the publication array at the top of `script.js` to update titles, years, citations, venues, authors, and Scholar IDs.
- Edit colors and styling in `styles.css`.
- Replace the Google Scholar November 2026 metrics snapshot when newer verified numbers are available.
- Add an email, ORCID, LinkedIn, and CV link when you want to publish those details.

## Academic record note
This website faithfully includes the 19 supplied Google Scholar entries, including an apparent duplicate and a retraction notice. The retracted work and its notice are labeled explicitly. Bibliographic details with ellipses are incomplete in the supplied source and should be checked before replacing with full details.

The website does **not** automatically synchronize citation counts with Google Scholar. Such synchronization would require a supported data feed or backend.

## Social and academic links
The homepage and Contact section include Google Scholar, ORCID, LinkedIn, ResearchGate, Facebook, and GitHub profiles provided by the site owner. Edit the URLs in `index.html` to update these.
